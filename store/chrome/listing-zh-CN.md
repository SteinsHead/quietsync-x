# Chrome Web Store 上架文案（简体中文）

## 名称

QuietSync for X

## 一句话介绍

订阅、分类和审核远程词库，再安全写入 X 原生屏蔽词。

## 详细介绍

网上有不少认真维护的垃圾内容词库，X 也有自己的「Muted words」，但把两边接起来一直很麻烦。

QuietSync 会定时取回你主动订阅的词库，在浏览器本地去重、整理和分类。你可以先看一遍结果，关掉太宽泛或不合适的词，再把确认过的内容写入 X 自己的屏蔽词。写进去之后，它们跟着 X 账户走，手机、平板和其他电脑也能生效。

你可以用它来：

- 订阅公开词库，或添加自己的 HTTPS TXT / JSON 地址；
- 合并重复项，整理空格、大小写和常见的不可见字符；
- 按诈骗、推广、互动诱导、加密、成人、骚扰、政治、AI 低质等类别审核词条；
- 只同步新增内容，默认不删除你已经在 X 里保存的词；
- 在同步前选择主页时间线、通知、来源范围和屏蔽期限；
- 导出本地备份，或随时停止正在进行的同步。

QuietSync 不会替你决定该看什么。自动同步默认关闭；普通同步也需要你先选择词条，再亲手确认。

### 隐私

QuietSync 没有账号系统、广告、统计或遥测。来源地址、词条、审核结果和同步记录保存在浏览器本地。取回词库时不会附带 Cookie、X 账号数据或来源页面信息。

扩展只会在 X 的屏蔽词设置页上工作，通过眼前看得见的表单逐条保存；它不读取密码、Cookie 或浏览历史，也不调用 X 的私有 API。

远程词库服务器仍会像普通网站一样看到连接所需的 IP 地址和 User-Agent。导出的完整备份可能包含私人词条和来源地址，公开分享前请先检查并删掉敏感内容。

### 使用前请留意

- QuietSync 不是 X 官方产品，也与 X Corp. 没有关系。
- X 的屏蔽词主要影响主页时间线和通知，不会过滤搜索结果。
- X 改动网页后，自动填写可能暂时失效；QuietSync 会停下来，不会猜着乱点。
- 第一次同步大词库时，建议先用 20–50 个词做一次小批量测试。
