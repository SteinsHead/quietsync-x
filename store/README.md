# Store submission kit

这里放的是 QuietSync 的浏览器商店上架材料，不会打进用户安装的扩展包。

- `chrome/listing-zh-CN.md`：中文商店介绍
- `chrome/listing-en-US.md`：英文商店介绍
- `chrome/privacy-declarations.md`：单一用途、权限和数据处理说明
- `chrome/reviewer-notes.md`：审核员测试步骤
- `edge/listing.md`：Edge Add-ons 复用说明
- `assets/`：商店图标、截图与推广图

正式提交前，仍需在开发者后台确认联系邮箱、分发地区、语言、数据披露勾选项和是否公开发布。不要在这些文件或截图里加入邮箱、账号 ID、Cookie、token、私人词库或真实同步记录。
